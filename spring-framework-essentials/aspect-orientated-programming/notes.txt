AOP(Aspect Oriented Programming)
-------------------------------
- enables modularization of cross cutting concerns
- examples: logging/tracing, caching, error handling, etc.
- check role before every method in application is a cross cutting concern
  because every method requires this check
- without modularization leads to code tangling aka coupling of concerns
- aop solves for code tangling and code scattering

Core AOP Concepts
------------------
    Join Point
     - a point in the execution of a program such as a method call 
       or exception thrown
    
    Pointcut 
      - an expression that selects one or more join points
    
    Advice
      - code to be executed at each selected join point 
    
    Aspect
      - a module that encapsulates pointcuts and Advice
    
    Weaving
      - aspects are combined with main code

Proxy
------
    - someone who stands in place of someone else 
    
    AOP Proxy
    - an enhanced class that stands in place of your original 
      with extra behavior
