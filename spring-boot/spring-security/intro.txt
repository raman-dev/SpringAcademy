Security Concepts
-----------------
    Principal 
        - user, decice or system that performs an action
    Authentication
        - validated Principal's credentials
    
    Authorization 
        - determine if Principal is allowed access to some resource
    Authority 
        - Permission or credential enabling access(such as role)
    Secured Resource 
        - Resource that is being secured
